# Active Directory Homelab

A hands-on Active Directory and Windows Server lab built using
Windows Server 2016 running in Oracle VirtualBox.

## Environment

- Windows Server 2016
- Oracle VirtualBox
- Active Directory Domain Services
- DNS
- Group Policy
- Active Directory Users and Computers
- PowerShell

## Lab Work

### 1. Active Directory Domain Services
Installed the AD DS role and configured the Windows Server as a Domain Controller.

### 2. Domain Controller
Configured the domain, DNS server and Global Catalog.

### 3. Users and Groups
Created and managed users and security groups using Active Directory Users and Computers.

### 4. Group Policy
Configured password and account policies using Group Policy.

### 5. PowerShell
Used PowerShell and Active Directory cmdlets for administration and automation.
